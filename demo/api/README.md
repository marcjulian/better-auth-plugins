# Api

Create your API and deploy it anywhere with this Nitro starter.

## Getting started

```bash
npm install
npm run dev
```

## Deploying

```bash
npm run build
```

Then checkout the [Nitro documentation](https://nitro.build/deploy) to learn more about the different deployment presets.

## Better Auth

Run the following command to update prisma schema base on the Better Auth configuration:

```bash
pnpm dlx auth generate --config server/utils/auth.ts
```
